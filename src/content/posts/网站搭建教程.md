# 搭建博客教程[基础教程·壹]

## 准备工作
前言：
### 1. 下载安装必要软件

**首先需要下载并安装以下软件：**

- [Mizuki](https://github.com/xieqsei/YanxMizuki/) - 博客框架
- [Visual Studio Code (VSCode)](https://code.visualstudio.com/) - 代码编辑器
- [Github Desktop](https://github.com/apps/desktop) - Git图形化界面工具
- [GithubDesktopZhTool](https://github.com/robotze/GithubDesktopZhTool) - Github Desktop汉化工具
- [Node.js](https://nodejs.org/zh-cn) - JavaScript运行环境

> 可通过超链接直达官网~

> 备注：这些下载将包括后续步骤，建议全部下载
---

## 环境配置
### 解压与安装
- 依次安装 **VSCode**，**Github Desktop** 和 **Node.js**

- 将Mizuki框架解压到一个你中意但不容易变动位置的位置，比如 "D:\Mizuki\"

完成该步骤便可进行接下来的步骤！

### 安装包管理工具和依赖

> 右键资源管理器界面，选择'在此处打开命令窗口'或者'终端',依次执行以下命令：

```bash
# 安装pnpm包管理器
npm install -g pnpm

# 安装项目依赖
pnpm install
```

> 提醒:建议在Mizuki目录里执行，避免安装错位置

---

## 项目初始化

### 安装项目依赖

在项目根目录下执行：

```bash
pnpm install
```

此命令会根据`package.json`文件安装所有必要的依赖包。

---

## 启动博客

完成以上步骤后，你可以使用以下命令启动博客：

```bash
# 开发模式启动
pnpm dev

```
---

其它：
```bash
#建生产版本
pnpm build

# 检查git版本（确认git已正确安装）
git --version
```

# 将Mizuki放到Github个人仓库里[基础课程·贰]
> 由于使用了Github Desktop工具,我们省去了非常多的专业步骤，减少了很多不必要的报错！

> 在此之前，你需要注册Github账号，并且在默认浏览器里登陆了账号，因为Github Desktop会关联浏览器里的Github。
## Github Desktop
### 汉化Github Desktop
> 如果你对你的英语没有多少信心，那么这一个步骤将会帮到你，且接下来的步骤将全用汉化版来说

- 打开Github Desktop汉化工具，点击左上角的**汉化**,之后就可以关掉了。

### 创建仓库
- 登录GitHub Desktop

- 点击左上角的**文件**,点击**新建存储库**(备注：记得存储位置,仓库位置与你解压的Mizuki位置应不一致)

> 注意：如果你只有一个静态网站需求，存储库名称建议为 "<你的github名字>.github.io" , 许可证选择MIT LICENSE(也可以不选)

- 操作之后就创建完了一个仓库了,进入新页面后可以直接将文件复制到仓库位置,GitHub Desktop会检测文件变动的

> 特别注意，复制时别复制**node_modules**文件夹，因为这个文件夹不仅大而且对网站半点用都没有(第三方库和模块)

- 复制完后在**摘要(必填)**那里填写备注,随后点击**Commit 1 flie to *main**

- 点击完后点击右上角的**同步(拉取然后推送) origin**,如果出现(0/146)读条的情况就是成功了。

# 将博客部署到Netlify[基础教程·叁]
> 在此之前，你需要注册Netlify账号，并且在同个浏览器里登陆了Github账号，因为Netlify会关联浏览器里的Github。
##创建新项目
在 Netlify **项目(projects)** 页面上，点击 **添加新项目(Add a new site)**

选择 **导入现有项目(Import an existing project)**

选择 **Github**

选择你上一步创建的新仓库

> 填写**项目名称(Project name)**时需要注意，这关乎于你的域名

当你从你的 Git 提供商中导入 Astro 仓库时，Netlify 应该会自动检测并预填充正确的配置设置。

确保已输入以下设置，然后按下 Deploy 按钮：
**构建命令(Build Command)**: astro build or npm run build
**发布目录(Publish directory)**: dist

部署后，你将被重定向到站点概览页面。在那里，你可以编辑你站点的详细信息。

根据你的部署配置，未来对源代码库的任何修改都将触发预览和生产部署。

netlify.toml 文件

你可以选择在项目仓库的顶层创建一个新的 netlify.toml 文件，用来配置你的构建命令和发布目录，以及其他项目设置，包括环境变量和重定向。Netlify 将读取此文件并自动配置你的部署。

为了配置默认设置，创建一个 netlify.toml 文件，并填入以下内容：

```bash
[build]
  command = "npm run build"
  publish = "dist"
```
更多信息可以在 Netlify 的博客文章 部署现有的 Astro Git 仓库 中找到。

---

(可选)
CLI 部署方式
你也可以在 Netlify 上创建一个新的站点，并通过安装和使用 Netlify CLI 来关联你的 Git 仓库。

全局安装 Netlify CLI 工具

```bash
npm install --global netlify-cli
```
运行 netlify login 并按照指示进行登录并授权 Netlify。

运行 netlify init 并按照指示进行操作。

确认你的**构建命令 (astro build)**

CLI 将自动检测**构建设置（astro build）**和**部署目录（dist）**，并将提供一个自动生成且有这些对应设置的 netlify.toml 文件。

推送到 Git 来触发构建和部署

CLI 将向仓库添加一个部署密钥，这意味着每次你使用 git push 时，你的网站都会在 Netlify 上自动重新构建。

---

如果不出意外的话,这个 "<项目名字>.netlify.app"就是你的域名了，你可以通过域**管理(domain-management)**查看域名,也可以直接访问这个域名
