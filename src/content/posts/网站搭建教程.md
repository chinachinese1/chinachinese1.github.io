# 搭建博客教程

## 准备工作

### 1. 下载安装必要软件

**首先需要下载并安装以下软件：**

- [Mizuki](https://github.com/xieqsei/YanxMizuki/) - 博客框架
- [Visual Studio Code (VSCode)](https://code.visualstudio.com/) - 代码编辑器
- [Github Desktop](https://github.com/apps/desktop) - Git图形化界面工具
- [Node.js](https://nodejs.org/zh-cn) - JavaScript运行环境

> 可通过超链接直达官网~

---

## 环境配置

### 2. 安装包管理工具和依赖

打开命令行工具（CMD或PowerShell），依次执行以下命令：
> 右键资源管理器界面，选择'在此处打开命令窗口'或者'终端'

```bash
# 安装pnpm包管理器
npm install -g pnpm

# 检查git版本（确认git已正确安装）
git --version

# 安装项目依赖
pnpm install
```

> 提醒:建议在Mizuki目录里执行，避免安装错位置
---

## VSCode插件安装

### 3. 安装必要的VSCode插件

在VSCode中安装以下插件以提高开发效率：

- **Chinese (Simplified) Language Pack** - 简体中文语言包
- **Markdown Preview Github Styling** - Markdown预览插件

**安装方法：**
1. 打开VSCode
2. 点击左侧扩展图标
3. 搜索插件名称
4. 点击安装

---

## 项目初始化

### 4. 安装项目依赖

在项目根目录下执行：

```bash
pnpm install
```

此命令会根据`package.json`文件安装所有必要的依赖包。

---

## 启动博客

完成以上步骤后，你可以使用以下命令启动博客：

```bash
# 开发模式启动
pnpm dev

# 或构建生产版本
pnpm build
```

---

## 注意事项

- 确保所有软件都正确安装并添加到系统PATH
- 如果遇到权限问题，请尝试使用管理员权限运行命令行
- 网络问题可能导致安装失败，可尝试使用国内镜像源

祝你搭建顺利！🎉
